# Inventory feature register

Suite architecture standard, step 4 (Sinu, 27 Nov 2026). It lists every feature live today, the
decision it came from, where it lives, and the tests that hold it. Safety comes before clever, and
nothing is added without a real problem.

**How it is kept**

- `test/feature-register.test.js` reads this table. It fails when a row names no test, or names a
  test that no longer exists.
- `npm run deploy`, for the Worker and the Pages client alike, runs every test first and stops on
  any failure. A feature that loses its test therefore blocks the deploy.
- A new feature gets a row and a test in the same commit. A feature removed with Sinu's word loses
  its row in that commit and goes into the release notes.
- **Decision** says where the feature came from. "First build" means the Herbal Park build of
  Nov 2026 (Sinu's brief); later decisions name the day, or the Design Guide card (D-0xx).
- **Tests** are `file: the start of the test's title`, separated by `;`.
